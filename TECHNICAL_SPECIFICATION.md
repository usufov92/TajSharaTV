# TECHNICAL_SPECIFICATION.md — TajSharaTV

## 1. Назначение

TajSharaTV — система для автоматизации управления IPTV-клиентами и подписками дилеров (TajSharaTV, Taj-IPTV). Поддерживает автоматизацию через Selenium, Telegram-уведомления, SMS, гибкую систему скидок и строгую безопасность.

---

## 2. Архитектура

- **Два независимых инстанса**: TajSharaTV и Taj-IPTV (разные .env, базы, порты)
- **Backend**: Django 4+, Python 3.12+
- **Frontend**: Django templates, Bootstrap
- **Автоматизация**: Selenium WebDriver, webdriver-manager
- **Интеграции**: python-telegram-bot, SMS (SmsMobile)
- **Хранение**: SQLite (по умолчанию), поддержка PostgreSQL
- **Логирование**: отдельные каталоги logs/

---

## 3. Основные бизнес-функции

- Управление клиентами, профилями, балансами, транзакциями
- Автоматизация добавления клиентов и покупки пакетов через Selenium
- Telegram-уведомления о всех ключевых событиях (с указанием инстанса)
- SMS-уведомления о продлении
- Гибкая система скидок (авто + ручная)
- Поддержка Windows Task Scheduler
- Разграничение прав (админ/менеджер)
- Логирование всех действий

---

## 4. Безопасность

- Все секреты и ключи — только в .env/.env.iptv
- DEBUG=False для продакшн
- CSRF и custom error page
- .gitignore защищает .env, логи, временные файлы
- Логирование всех действий пользователей

---

## 5. Развёртывание и эксплуатация

### 5.3 Client (Клиент)
```python
- id: BigAutoField (PK)
- username: CharField (150, уникальное, индекс)
- password: CharField (150)
- phone: CharField (20)
- subscription: CharField (255) - названия пакетов
- start_date: DateField - дата начала подписки
- end_date: DateField - дата окончания (индекс)
- info: TextField - дополнительная информация
- created_at: DateTimeField (авто)
- updated_at: DateTimeField (авто)
- created_by: ForeignKey → User (SET_NULL)

Методы:
- remaining_days: свойство - оставшиеся дни
- status: свойство - статус (active/expired/pending)
- status_display: свойство - текстовое представление
```

### 5.4 Transaction (Транзакция)
```python
- id: BigAutoField (PK)
- manager: ForeignKey → User (SET_NULL)
- client: ForeignKey → Client (CASCADE)
- packages: TextField - список купленных пакетов
- total_cost: DecimalField (10, 2) - стоимость
- days_purchased: IntegerField - куплено дней
- created_at: DateTimeField (индекс)

Индексы:
- created_at
- (manager, created_at)
```

## 7. ОСНОВНЫЕ ФУНКЦИИ

### 7.1 Автоматизация через Selenium

#### Процесс добавления клиента:
1. **Инициализация браузера** (headless Chrome)
2. **Авторизация** на сайте дилера
3. **Переход** на форму добавления клиента
4. **Заполнение** формы (логин, пароль, комментарий)
5. **Сохранение** клиента
6. **Переход** в панель дилера
7. **Выбор** клиента
8. **Выбор** пакета
9. **Выбор** срока (360 дней)
10. **Оформление** покупки
11. **Проверка** успешности операции
12. **Закрытие** браузера

#### Обработка ошибок:
- Повторные попытки (до 3 раз)
- Логирование всех действий
- Скриншоты при ошибках
- Таймауты с настройкой

### 7.2 Расчёт стоимости пакетов

#### Формула:
```
Стоимость = Σ (Цена_пакета / 30 дней) × Количество_дней
```

#### Пример:
- Пакет "Базовый": $30/месяц
- Пакет "VIP": $50/месяц
- Период: 60 дней

```
Базовый: ($30 / 30) × 60 = $60
VIP: ($50 / 30) × 60 = $100
Итого: $160
```

### 7.3 Валидация данных

#### Клиент:
- Логин: мин 3 символа, уникальный
- Пароль: мин 4 символа
- Телефон: формат +992XXXXXXXXX (опционально)

#### Пакеты:
- Минимум 1 пакет
- Даты: начало <= окончание
- Минимум 1 день подписки

#### Баланс:
- Сумма пополнения: $1 - $10,000
- Достаточно средств для покупки
